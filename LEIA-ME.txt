PARA ATUALIZAR O GITHUB
1. Extraia o ZIP no Mac.
2. No repositório atual, use Add file > Upload files.
3. Envie TODOS os arquivos de dentro da pasta.
4. Confirme a substituição dos arquivos existentes e faça Commit changes.
5. Aguarde o GitHub Pages terminar o deploy.
6. Faça uma atualização forçada no navegador: Command + Shift + R.

Não envie o ZIP fechado ao repositório; envie os arquivos extraídos.
